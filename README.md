# Linguistics Guide / 语言学指南

[https://pinatsu0330-hash.github.io/Linguistic-Guide/](https://hanamode.github.io/Linguistic-Guide/)

This static site is organized around the chapter sequence of *An Introduction to Language*, 10th edition. Article text is written as concise original study notes in Chinese and English, rather than a verbatim reproduction of the textbook.

## Run locally
Open `index.html` in a browser. Use the `EN` / `中` controls in the top-right corner to switch the language shown across the page, navigation, chapter overviews, and article content. The preference is saved locally in the browser.

## Edit content
Each topic has its own HTML page in `articles/<chapter>/`. In an individual page, the two language panels are marked with `data-lang="zh"` and `data-lang="en"`. Chapter overview notes are stored in each `index.html`. CSS is in `css/style.css`, and navigation/language behavior is in `js/main.js`.
